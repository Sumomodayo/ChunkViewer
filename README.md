# ChunkViewer Plugin


## 概要
`ChunkViewer` は、Minecraft Bukkit/Spigot サーバー向けのプラグインで、プレイヤーが自分のいるチャンクの境界を簡単に視覚化できるようにします。  
パーティクルを使用してチャンクの境界を表示することで、土地管理や建築の際に非常に便利です。
java版、統合版の両方使用可能です

## 対応バージョン
- Minecraft 1.21.1.1 (Paper)
- Java Edition / 統合版対応 (Geyser などを介して統合版でも動作確認済み)

## 権限
- `chunkviewer.use` - チャンク境界表示コマンドを使用する権限

## コマンド
### `/chunkview on`
チャンク境界表示をオンにします。  
すでにオンの場合は通知されます。

### `/chunkview off`
チャンク境界表示をオフにします。  
すでにオフの場合は通知されます。
